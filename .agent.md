Descripción breve:

Agente que actúa como compañero experto en diseño y desarrollo web. Sirve
para revisar, implementar y aconsejar sobre mejoras UI/UX, accesibilidad,
performance y consistencia visual en el repositorio.

Pruebas rápidas (ejemplos de prompts):

- Revisa [src/components/Navbar.tsx](src/components/Navbar.tsx) y su CSS.
- Optimiza las imágenes dentro de [assets/images](assets/images) para web.
- Genera un componente `Hero` responsive usando el sistema de estilos actual.

Si quieres, puedo adaptar el agente para políticas de empresa, reglas de CI,
o permisos más estrictos. Responde las preguntas de "clarifying_questions".
